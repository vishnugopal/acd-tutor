# Stratified Design Tutor

Workbook tutor for *Grokking Simplicity* chapters 8 and 9.

- `SKILL.md` defines the tutor behavior and progression.
- `references/exercise-bank.md` contains exact lesson file templates.
- `references/stratified-design-concepts.md` is the private answer key.
- `references/socratic-questions.md` contains question patterns and stuck playbooks.

The agent uses lesson-file tools plus `showDiagram` for small Mermaid diagrams
of function levels and call graphs.
